# Phase 0: Project Bootstrap and Readiness

This folder contains the phase-wise organized source and tests for Phase 0.

## Structure

- `phase0/src`: Phase 0 source code
- `phase0/tests`: Phase 0 tests
- `phase0/scripts/run_phase0.py`: Phase 0 bootstrap runner

## Run

From project root:

```bash
python phase0/scripts/run_phase0.py
```

## Test

```bash
python -m pytest -q phase0/tests
```
